# Подробная история реверса и портирования FH8626V100

Этот файл дополняет `CHRONOLOGY.md`. Основная хронология должна оставаться короткой; сюда выносятся только те детали, которые объясняют важную развилку, неудачный подход, метод доказательства или технический контракт.

## Правила

- Не копировать чат, команды или длинные логи.
- Не хранить секреты, пароли, приватные адреса/идентификаторы и эмоциональные реплики.
- Не фиксировать каждую промежуточную проверку.
- Сохранять детали только если они помогают:
  - понять, почему изменился подход;
  - не повторить уже пройденный тупик;
  - восстановить техническое доказательство;
  - передать важный метод новому агенту.
- Для актуальных точных контрактов ссылаться на текущую документацию проекта, если она уже существует, вместо дублирования.
